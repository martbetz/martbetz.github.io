--- title: RAW? layout: post categories: photography computing ---

“What does ‘RAW’ really stand for?” It’s a question I’m asked all the time. “Nothing” would be the short answer, which always gets followed by “Why?” Now, that is a good question — but the answer to that one’s slightly more involved.

The following post is a product of personal research. I’m neither a professional nor an expert — so don’t scratch that head of yours too hard, young Bob; you know what happened the last time.

TIFF, GIF, AVIF... and (of course) JPEG; we’re all very used to those funny little nonsense names we like to give our file types, all of them being acronyms or initialisms in some form or other. It seems a fair assumption, then, that ‘RAW’ should be one too; after all, it certainly looks like it should — it’s pretty much written in capitals almost everywhere you look, and everyone talks about “shooting in RAW” as though it’s a format in its own right.

The funny thing is, though, none of those things are true.

‘RAW’ (or more accurately ‘raw,’ as you’re about to find out) is a general collective term given to the data that’s captured by digital cameras. Think of it as a modern equivalent of a film negative: it’s the original image information straight from the camera sensor, before most of the processing and interpretation takes place.

What happens to that sensor data depends on the camera, its firmware, and the settings chosen by the photographer. Sometimes the camera processes the data immediately and saves a finished JPEG. Other times, the original data is retained and stored in a file so that it can be processed later using specialist software.

Those files are what we call raw files, and this is where things start to get interesting.

As we’re very much all aware, there isn’t just one universal “raw format,” — every manufacturer has traditionally done things slightly differently, and here are a handful of common examples:

  • RAF (Fujifilm)
  • CR2 (Canon)
  • NRW (Nikon)
  • ARW (Sony)
  • ORF (Olympus)
  • MRW (Minolta)
  • PEF (Pentax)

Most of these names are initialisms derived from the manufacturer or the format’s technical origins (some perhaps more creatively than others — Fujifilm?!). Despite their different names, however, they all serve the same broad purpose: they store raw image data.

So, here are the takeaways so far:

  1. ‘raw data’ collectively refers to the data that’s captured by a digital camera
  2. ‘raw file’ collectively refers to a file that contains raw data
  3. ‘raw’ is not a specific image format in and of itself (actually, there is one exception; more on that shortly 😶)
  4. ‘raw’ is neither an acronym nor an initialism

Which brings us neatly back to the original question: if ‘raw’ isn’t an acronym or an initialism, why do so many people write it as ‘RAW’? The honest answer is we shouldn’t; strictly speaking, it should be written as ‘raw.’ — the capitalisation has become so widespread that many people simply assume it’s correct, but the convention appears to have grown largely through repetition rather than necessity.

As far as the misconception goes, there are several likely contributors:

  1. the misplaced trust of common practice
  2. the understandable assumption that it must be capitalised because most image formats are
  3. the belief that ‘RAW’ is somehow a special technical term distinct from the ordinary word ‘raw’

In other words, once enough people started writing it in capitals, everybody else followed suit.

However, just to be plain-old awkward, here’s the weird and wonderful exception: ‘RAW,’ does exist as a file extension for certain Panasonic and Leica raw files — and in that particular context, ‘RAW’ is indeed an actual file type; but unlike most of the others, it still isn’t an acronym or initialism!

So there we have it: ‘RAW’ doesn’t stand for anything — it’s simply a descriptive term for unprocessed image data and, by extension, the files that contain it. 😎
